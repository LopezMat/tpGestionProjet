# T-054 — API de consultation des disponibilités (F-01, lecture seule)

## Description
**Origine.** Changement de priorité d'Ethan du 2026-11-25 : développer d'abord le socle et la partie de F-01 réalisable sans authentification (option « Lecture seule »). La réservation reste dans [T-018](T-018-disponibilites-reservation.md), qui dépend de l'authentification (T-013). Ce ticket détache de T-018 la partie consultation : `GET /api/salles` et `GET /api/disponibilites?date=` (architecture § 3 et § 4, composant `api.reservations`), sur le modèle de T-011 et les règles de T-012.

**Caractère provisoire de l'accès.** En attendant T-013 et la matrice d'autorisation de T-020, ces deux routes répondent sans connexion. C'est un écart temporaire au CDC (F-04 : « toute page ou appel d'API de réservation sans connexion est refusé ») : T-013 et T-020 devront les placer derrière l'authentification. Les réponses ne contiennent aucune donnée personnelle.

## Critères d'acceptation
- [x] `GET /api/salles` renvoie les 3 salles (nom ; capacité et équipements facultatifs).
- [x] Pour une date donnée, `GET /api/disponibilites?date=AAAA-MM-JJ` renvoie pour chacune des 3 salles les créneaux d'une heure, chacun marqué « libre » ou « occupé », **sans aucun nom ni e-mail** d'occupant.
- [x] **Horaires** : les créneaux renvoyés vont de 8 h-9 h à 19 h-20 h (12 par salle et par jour) du lundi au vendredi ; aucun créneau n'est renvoyé pour un samedi ou un dimanche (tests sur un jour ouvré, un samedi et un dimanche).
- [x] Une réservation présente en base pour un créneau (insérée par le test) fait apparaître ce créneau « occupé » ; les autres restent « libres ».
- [x] Une date invalide (format incorrect) renvoie une erreur 422 explicite, sans erreur serveur.
- [x] Le temps de `GET /api/disponibilites` est mesuré en test d'intégration et reste sous 2 s (H-05).
- [x] Le caractère provisoire de l'accès sans connexion est signalé dans le code (commentaire renvoyant à T-013 et T-020) et une ligne est ajoutée au journal de T-020 pour que la matrice d'autorisation couvre ces deux routes.
